Personal Projects

LLM Hallucination Detection

Research project at Yang Lab focused on detecting and analyzing the origins of hallucinations in large language models. This work involves developing novel methodologies to trace and identify when LLMs generate content that isn't grounded in their training data.

Technologies: PyTorch, Transformers, Natural Language Processing

Geometric Processing Space of LLMs

Research at CRIS Lab analyzing how LLMs process and interpret emotions in text through their geometric processing spaces. This project maps the multi-dimensional representation spaces within language models to understand emotional content processing.

Technologies: TensorFlow, Vector Space Modeling, Sentiment Analysis

Automated Accounting Agent

Developed an automated accounting agent during my internship at Muse (Summer 2024) using fine-tuning and Retrieval Augmented Generation techniques. The agent can process financial documents, extract relevant information, and perform basic accounting tasks.

Technologies: RAG, LLM Fine-tuning, OCR, Financial Data Processing

AI Media Technologies

During my 2023 software engineering internship, I contributed to building media analysis tools and content recommendation systems. Worked on backend infrastructure and API development.

Technologies: Python, Django, PostgreSQL, Machine Learning
